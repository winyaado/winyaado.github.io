# ぬこ ポートフォリオ

## ZEN大学 Webアプリケーション開発1

これは、レトロなWindows 3.1テーマの個人ポートフォリオウェブサイトです。

### 機能

*   **プロフィール**: 「ぬこ」の自己紹介。
*   **スキル**: 技術スキルと経験の概要。
*   **活動内容**: 過去のプロジェクトへのリンク。
*   **連絡先**: 連絡先情報。
*   **フォト**: シンプルな写真ギャラリー。
*   **おみくじ**: 日本のおみくじゲーム。

### 実行方法

これは静的なウェブサイトです。`index.html`をウェブブラウザで開くだけでポートフォリオを閲覧できます。

## ZEN大学 Webアプリケーション開発2

Webアプリケーション開発1の成果物に、動的なアンケート機能を追加しました。

### 追加機能

*   **アンケート (犬派 vs 猫派)**: 
    *   ユーザーは「犬」か「猫」に投票できます。
    *   リアルタイムで投票結果が棒グラフと数値で表示されます。
    *   IPアドレスによる1日1回の投票制限があります。

### 導入方法

この機能を使用するには、PHPとデータベース（MySQL等）の環境が必要です。

#### 1. データベースのセットアップ
`server/SQL/setup.sql` を使用して、データベースに `votes` テーブルを作成してください。

#### 2. 設定ファイルの編集
`server/PHP/config.php` を開き、以下のデータベース接続情報を環境に合わせて変更してください。
- `DB_HOST`
- `DB_NAME`
- `DB_USER`
- `DB_PASS`
- `IP_SALT` (必要に応じて)

#### 3. 画像ファイルの配置
以下のパスに画像ファイルを配置してください。
- `img/poll/icon.png` (デスクトップアイコン用)
- `img/poll/dog.png` (犬の画像)
- `img/poll/cat.png` (猫の画像)

#### 4. サーバーの起動と実行
PHPサーバーを起動し、ブラウザで `index.html` にアクセスしてください。
※ `js/poll.js` 内の `API_BASE_URL` がサーバーのエンドポイントと一致していることを確認してください。
